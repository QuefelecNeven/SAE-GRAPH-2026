# SAE GRAPH 2026

Projet Maven pour la gestion de livres interactifs avec énigmes.

## Structure du projet

```
SAE-GRAPH-2026/
├── src/
│   ├── main/java/              # Code source principal
│   │   ├── Debut.java
│   │   ├── Enigme.java
│   │   ├── Executable.java
│   │   ├── Fin.java
│   │   ├── Livre.java
│   │   ├── Objet.java
│   │   └── Page.java
│   └── test/java/              # Tests unitaires
│       ├── ExecutableEnigmes.java
│       └── TestLivre.java
├── L0rem IpsUm/                # Dépendances externes (LoremIpsum JAR)
├── Rapports/                   # Documentation
├── pom.xml                     # Configuration Maven
└── README.md
```

## Build et exécution

### Compiler le projet
```bash
mvn clean compile
```

### Exécuter les tests
```bash
mvn test
```

### Créer un JAR exécutable
```bash
mvn clean package
```

### Exécuter l'application
```bash
java -cp target/sae-graph-2026-1.0-SNAPSHOT-jar-with-dependencies.jar fr.iut.sae.Executable
```

## Dépendances

- **Java 17** : Version du compilateur et de la cible
- **JUnit Jupiter 5.10.2** : Framework de test
- **LoremIpsum 1.0** : Génération de texte Lorem Ipsum

## Notes

- Le projet utilise Maven pour la gestion des dépendances et du build
- La classe principale est `fr.iut.sae.Executable`
- Les tests sont situés dans `src/test/java/`
